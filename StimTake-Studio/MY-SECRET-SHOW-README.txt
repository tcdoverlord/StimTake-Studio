MY SECRET SHOW — CREATOR CAM 4.0 MODULE
=======================================

My Secret Show is now embedded in Creator Cam's modular overlay payload.
There is no separate controller page and no separate local server.

HOW TO USE
----------
1. Start Creator-Cam-Overlay-Kit.exe normally.
2. Keep the existing Creator Cam URL in OBS:
   http://127.0.0.1:8787/index.html
3. Open the Backstage Dashboard.
4. On the main Dashboard tab, scroll to:
   MY SECRET SHOW • MANUAL OBS CAMERA COVER
5. Change the price, text, theme, intensity, or duration and click:
   SAVE + APPLY SETTINGS
6. Use Lock, Unlock, Cancel, Test, Reset, and Tease View there.

TRANSPARENCY + TEASE VIEW
-------------------------
- There is no separate black overlay or Blackout layer. Only the main My Secret
  Show artwork is rendered over the transparent OBS browser source.
- Set normal source opacity yourself in OBS Studio if desired.
- Tease View completely hides the entire camera cover so the camera is clear.
- Decorative cover animations and rotating messages pause during the tease.
- Tease seconds can be set from 1 to 180 seconds (3 minutes). It automatically
  returns to LOCKED when the timer ends.
- A full Unlock removes the module iframe from the OBS composition so the
  camera is visible instead of a black browser-source frame.

SAFETY
------
- The module starts locked with the main My Secret Show artwork visible.
- Test Animation always returns to locked without exposing the camera.
- Tease View always auto-locks after its configured time.
- Repeated Tease View presses safely restart one authoritative auto-lock timer.
- The settings are stored in the Creator Cam profile and are included when the
  profile is exported.

IMPORTANT LIMITATION
--------------------
This is a manually controlled visual OBS camera cover. It does not detect tips
and does not control Chaturbate Hidden Cam permissions.
