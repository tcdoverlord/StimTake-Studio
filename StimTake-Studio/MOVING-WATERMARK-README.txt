MOVING WATERMARK — CREATOR CAM MODULE UPGRADE
================================================

This upgrade adds the Obsidian Stallion moving-watermark style directly to the
existing Creator Cam overlay. It remains a transparent OBS overlay element.

HOW TO USE
----------
1. Start Creator Cam and open the Backstage Dashboard.
2. Scroll below My Secret Show to:
   MOVING WATERMARK • OBSIDIAN STALLION STYLE
3. Edit any of the three saved text lines:
   - Glowing title
   - Name / username
   - Tagline
4. Click SAVE + SHOW to save the text and display it.
5. Click SAVE CHANGES to update the saved text without changing visibility.
6. Click HIDE to save the text and hide the watermark.

The watermark moves fluidly from the bottom to the middle and then to the top
of the 1920 x 1080 OBS canvas. Saved text and visibility return after restart.

The overlay also refreshes the saved watermark settings directly from Creator
Cam every 1.5 seconds. This makes SAVE + SHOW reliable even if OBS opened after
another dashboard event, refreshed its browser source, or missed an event.
The protective watermark remains visible during Stream Safe Mode when enabled.

This module does not change My Secret Show or the other working modules.
