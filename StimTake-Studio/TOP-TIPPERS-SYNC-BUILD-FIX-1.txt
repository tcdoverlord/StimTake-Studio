Windows compiler evidence received
----------------------------------
CS0122 / CS0103 / CS1061 around Match, Regex, RegexOptions.
CS0160 because ObjectDisposedException was placed after InvalidOperationException.

Cause
-----
1. CreatorCamLauncher.cs already imports System.IO.Compression. The new parser
   used unqualified Match / Regex names without importing the regular-expression
   namespace, so the old .NET compiler resolved Match incorrectly.

2. ObjectDisposedException derives from InvalidOperationException. The general
   catch was placed before the specific catch, making the second catch unreachable.

Smallest repair
---------------
- Fully qualified only the new regular-expression types:
  System.Text.RegularExpressions.Match
  System.Text.RegularExpressions.Regex
  System.Text.RegularExpressions.RegexOptions

- Reordered the two catch clauses:
  ObjectDisposedException first
  InvalidOperationException second

No tip logic, supporter logic, connector logic, UI logic, payload, or Studio V3
logic was rewritten.
