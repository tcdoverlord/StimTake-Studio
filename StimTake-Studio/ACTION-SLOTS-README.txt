STIMTAKE V1 ACTION SLOTS
========================

ACTION BUTTON BEHAVIOR
- Each Action number is a true ON/OFF toggle.
- Click an assigned Action once: ON.
- Click the same Action again: OFF.
- There is NO Studio host timer for Action slots.
- An Action remains loaded until you click it OFF, use STOP SELECTED / STOP ALL, replace/clear the slot, or the HTML itself chooses to hide/end.
- Turning an Action OFF unloads its iframe so its animation, sound, and JavaScript stop immediately.

BUTTON COLORS
- Gray: empty slot.
- Green: assigned and OFF.
- Highlighted: ON/running.

CAMERA STARTUP
- My Secret Show starts UNLOCKED with the camera visible.
- Use LOCK only when you intentionally want the camera cover.

PROFILE DATA
- The bundled V1 example profile contains no saved viewer/tipper history.

UPDATED TOGGLE RULE
- Every button begins OFF/dark when Studio opens.
- Loaded/assigned does NOT change a button green.
- First click turns that Action ON and makes the button green.
- Second click turns that same Action OFF and returns it to dark.
- There is no Studio Action duration and no 120-second maximum for Action slots.
