STIMTAKE v9 - CHATURBATE TOP TIPPERS / FANS SYNC FIX
=====================================================

Observed live test
------------------
Working:
- normalized test tip reached StimTake
- Last Tipper updated
- tip popup appeared

Not working:
- the Windows Top Tippers / Fans board did not add/update the tipper

Root cause found in source
--------------------------
The overlay platform-event path received TIP events, but the ControlDeckForm
persistent `crew` list (the source for the Windows Top Tippers / Fans table)
was only changed by its manual Add/Update controls.

Fix
---
ControlDeckForm now listens to the existing StaticServer EventPublished event.

For a normalized platform event:
  type = tip
  username = viewer
  amount = token count

StimTake now:
1. Finds that username case-insensitively.
2. Adds the tip amount to the existing lifetime support total, OR creates a
   new Supporter/Bronze row if the viewer is new.
3. Preserves an existing creator-edited custom label and tier.
4. Re-sorts the board by lifetime support, highest first.
5. Saves the existing tippers.tsv file.
6. Publishes supporters-sync so the OBS supporter board receives the refreshed
   saved ranking.

No fake Chaturbate API behavior was added. The connector format remains the
same.
