TCDOVERLORD ACTION OVERLAY PRELOADS - EDITABLE PACK
===================================================

This separate pack contains all six Action overlays that older Creator Cam builds assigned automatically:

01 - Black Cat
02 - Halloween Sides
03 - Flying Witch
04 - Warlock
05 - Pumpkin
06 - Ghost

HOW TO USE ONE
1. Extract the entire preload ZIP before editing or importing.
2. Open the numbered overlay folder.
3. Edit overlay.html and any files beside it.
4. Start Creator Cam v8 and open Backstage Dashboard > ACTION DECK.
5. Select any slot from 1-20.
6. Click BROWSE / REPLACE HTML and choose that folder's overlay.html.
7. Click the numbered Action button to run it.

Keep referenced asset folders beside overlay.html. Creator Cam copies supported local scripts, styles, images, audio, fonts, and video into the selected managed slot.

The preload pack is not automatically installed or assigned by v8.
