# StimTake Chrome Bridge V3

Receiver-only Chaturbate tip bridge for StimTake Studio 6.0.

V3 preserves the proven V2 DOM parser and adds:
- Studio `/api/studio-status` health
- locked-model display
- browser-room/model match
- accepted/duplicate/rejected delivery diagnostics
- Studio session tip/token counters

Load the `StimTake-Chrome-Bridge-v3.0` folder unpacked in Chrome.
